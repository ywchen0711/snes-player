# 超任模擬器 · SNES Player

Play Super NES games you own, right in the browser. Pick or drop a `.sfc` / `.smc` file (or a `.zip` holding one) and it starts. The page is in Traditional Chinese and English.

**Play:** https://ywchen0711.github.io/snes-player/

- **Your file stays with you.** The game file is read inside your browser and is never uploaded.
- **No games are included.** Use only games you legally own, such as a backup of your own cartridge, or homebrew that its author shares for free.
- **Controls:** arrow keys; Z / X / A / S for A / B / X / Y; Q / E for L / R; Enter for Start; V for Select. A gamepad works when plugged in, and phones and tablets get on-screen buttons.
- **Menu:** under the game there is full screen, save and load states, key settings and volume. Saves stay in your browser.
