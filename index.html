超任模擬器在瀏覽器裡玩你自己的超任遊戲

把遊戲檔拖到這裡

支援 .sfc、.smc（也可以是裝著它們的 .zip）

檔案只在你的瀏覽器裡執行，不會上傳到任何地方。這裡不提供任何遊戲，請只使用你合法擁有的遊戲（例如自己卡帶備份的檔案，或作者免費公開的自製遊戲）。

操作

方向鍵↑ ↓ ← →
A / B / X / YZ / X / A / S
L / RQ / E
Start / SelectEnter / V
手把直接插上就能用
手機、平板畫面上會出現虛擬按鍵

遊戲畫面下方的選單可以全螢幕、即時存檔／讀檔、改按鍵和調整音量。存檔留在這個瀏覽器裡。

模擬器：EmulatorJS 4.2.3 (GPL-3.0) 與 Snes9x 核心（非商業授權）。 Super Nintendo 是任天堂的商標，本頁與任天堂無關。
